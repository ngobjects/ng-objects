File upload: several files in one field

An input with the multiple attribute lets the user choose several files at once, and the browser sends them all under the field's name. <wo:fileUpload> handles one file per field, so this page uses a plain input and reads the files from the request in its action: 

if( context().request() instanceof NGMultipartRequest request ) {
	for( Part file : request.uploadedFilesForKey( "files" ) ) { ... }
}
