File upload: as a stream

For files too large to hold in memory, bind <wo:fileUpload>'s inputStream instead of data. The action then reads the file a buffer at a time. Here it measures the file and computes its SHA-256; a real application would store it.

The stream stays readable until the request has been handled. While the request is collected, the framework keeps a large file in a temporary file, which it deletes once the response has been sent. To handle a file while it's still arriving, see incoming parts.
