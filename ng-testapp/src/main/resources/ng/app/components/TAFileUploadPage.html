File upload: the whole file

The simplest way of receiving a file: <wo:fileUpload> sets its data binding to the file's content, as a byte[], and its filename binding to the file's name. Fine for files that comfortably fit in memory, like these images. For large files, see receiving the file as a stream.

Note the form's enctype="multipart/form-data". Without it, the browser sends only the file's name, not the file, and the upload field tells you so.
