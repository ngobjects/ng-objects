File upload: the body is the file

Apps and scripts often upload a file as the request's body itself, not inside a form: curl --data-binary @photo.jpg, or fetch( url, { method: "POST", body: file } ). A handler can read such a body in full with request().contentBytes(), or, for files too large to hold in memory, as a stream: 

try( InputStream in = request().contentStream() ) {
	in.transferTo( storage );
}

The body arrives once. Reading it as a stream keeps nothing, so it can't be read again afterwards. Reading it in full keeps it, and anything can read it after that. Code that sees every request, like logging, can describe the body without reading it, with request().contentType() and request().contentLength().
